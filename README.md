# FEA-of-Perforated-Cylindrical-Filter-Screens
Designed and analyzed perforated cylindrical filter screens for a gas scrubber application using SolidWorks and SolidWorks Simulation. Compared two perforation configurations (Ø3 mm and Ø5 mm) under pressure loading, evaluating von Mises stress and deformation to assess structural integrity and identify a suitable design.
